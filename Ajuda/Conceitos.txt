.sr-only = Apenas screen reader consegue ler

aria-label = Nome dados a elementos sem texto claro como nav, video etc. O screen reader lê isso.

aria-labelledby = Reaproveita o id para ser o texto que vai ser lido

aria-describedby = Associa um elemento com uma descrição mais longa, como um parágrafo

aria-current="page" = Indica que o botão atual representa a página que ele está agora
